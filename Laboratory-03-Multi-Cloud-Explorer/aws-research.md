# AWS Research

## Brief Overview

Amazon Web Services (AWS) is Amazon's cloud platform launched in 2006. It provides computing, storage, databases, networking, analytics, and security services.

## Global Infrastructure

AWS uses Regions and Availability Zones worldwide.

## Cloud Management Console

AWS Management Console

## Four Core Services

| Service | Purpose |
|----------|----------|
| Amazon EC2 | Virtual machines |
| Amazon S3 | Storage |
| Amazon RDS | Databases |
| AWS IAM | Identity management |

## Three Advantages

1. Broad service selection
2. Global infrastructure
3. High scalability

## Enterprise Use Cases

- Web hosting
- Databases
- AI/ML
- E-commerce
