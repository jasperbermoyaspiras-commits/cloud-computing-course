This activity helped me understand the differences and similarities among AWS, Microsoft Azure, and Google Cloud Platform (GCP). Before doing this activity, I knew that these platforms provided cloud services, but I did not fully understand how their services and strengths differ. By researching and comparing them, I learned that all three platforms provide important services such as computing, storage, databases, networking, and identity management. However, each platform also has its own strengths that can make it more suitable for specific business needs.

The cloud platform that impressed me the most was AWS because it offers a wide range of cloud services and can support different types of applications and organizations. I also learned that Azure is a good choice for organizations that already use Microsoft technologies because of its strong integration with products such as Windows Server and Microsoft 365. On the other hand, GCP stood out because of its strong capabilities in Artificial Intelligence, Machine Learning, and Kubernetes.

This activity also taught me that choosing a cloud provider should not be based only on popularity. Business requirements are very important when making a cloud decision. Factors such as the organization's existing technology, budget, application requirements, scalability, and technical needs should be considered before choosing a provider. For example, a university using Microsoft technologies may benefit more from Azure, while an AI research company may find GCP more suitable.

Acting as a Cloud Solutions Consultant helped me understand how technical decisions should be connected to actual business problems. I learned that there is no single cloud provider that is perfect for every organization.

Lastly, this activity improved my GitHub documentation skills. I learned how to organize research, comparison tables, recommendations, and other information using Markdown. Overall, this mission improved both my cloud computing knowledge and my ability to document technical information in an organized way.
