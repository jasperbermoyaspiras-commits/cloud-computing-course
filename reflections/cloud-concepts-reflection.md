Cloud computing has become an essential part of my daily routine because many of the digital services I use depend on cloud technology. 
Some of the cloud-based applications I frequently use are Google Drive, Facebook Messenger, and Canva.
These platforms make it easier to store files, communicate with others, and create digital content anytime and anywhere.

Google Drive is an example of Software as a Service (SaaS) because it enables users to save, organize, and access files online without installing specialized software. 
It follows the Public Cloud deployment model since it is accessible to anyone who has a Google account.

Facebook Messenger is another SaaS application because it allows users to send messages, make voice calls, and conduct video calls over the internet. 
It also uses the Public Cloud deployment model, as its services are available to millions of users around the world through an online platform.

Canva is also classified as SaaS because it provides online tools for creating presentations, posters, and other graphic designs without requiring users to install advanced design software. 
Since it is available to anyone with internet access and an account, it also operates using the Public Cloud deployment model.

Git and GitHub play a significant role in cloud computing projects by helping developers manage and organize their work efficiently.
Git keeps track of every change made to project files, allowing users to restore previous versions whenever necessary. Meanwhile, GitHub serves as a collaborative platform where team members can share code, review updates, and work together without accidentally overwriting each other's changes.
These tools improve teamwork, reduce errors, and make project management more organized.

Overall, cloud computing has greatly improved the way people access applications and manage information online. 
Through learning Git and GitHub, I realized that version control is an essential part of developing reliable cloud-based systems because it supports collaboration, enhances productivity, and ensures that project files remain well-organized and secure.
